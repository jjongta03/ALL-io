발급 계정용 `/login` 화면에서 이메일·비밀번호로 로그인하고 대시보드로 이동할 수 있습니다. 회원가입은 제공하지 않습니다. [계정 발급·로그인 API·검증](docs/AUTHENTICATION.md)을 참고하세요.

## 바로 실행

필수 환경: Node.js 24, npm. Docker·API 키·외부 DB 없이 실행할 수 있습니다.

```powershell
npm ci
npm run setup
npm run dev
```

브라우저에서 **http://127.0.0.1:3000** → **로컬 데모 시작** → **내 사업장 등록** → 4단계 입력 → **내 사업장 진단하기**. 기존 채용 계획은 마이페이지의 **기존 채용 계획**에서 사용할 수 있습니다.

같은 PC에서 이 작업으로 의존성을 설치했고 DB를 초기화했다면 `npm run dev`만 실행하면 됩니다. `localhost` 대신 설정된 `127.0.0.1` 주소를 사용하세요. CSRF Origin 검사가 적용되어 있습니다.

## 점검 명령

```powershell
npm run check
npm run build
npm run doctor
```

서버를 실행한 다른 터미널에서:

```powershell
npm run smoke
```

`doctor`는 키의 존재 여부만 표시합니다. 실제 키를 출력하지 않습니다.

## 중요한 로컬 DB 제약

PGlite는 간단한 로컬 개발을 위한 단일 프로세스 DB입니다. **서버 실행 중 별도 CLI에서 같은 DB를 열지 마세요.** 개발 중 작업 실행은 운영자 화면을 사용하고, `setup / doctor / db:* / jobs:run`은 서버를 끈 뒤 실행합니다. 여러 서버·Cron을 동시에 실행할 때는 PostgreSQL을 사용합니다.
