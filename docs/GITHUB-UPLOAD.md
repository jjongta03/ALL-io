# GitHub 업로드 범위

대상 저장소: https://github.com/jjongta03/ALL-io

2026-11-15 사용자가 요청한 백엔드를 실행·검토할 수 있도록 Next.js 서버, 기존 로컬 데모 화면, SQL 마이그레이션, 타입·DB 통합 테스트, HTTP 스모크, 설정 예시와 개발 문서를 함께 제공한다. Figma 디자인을 프론트엔드로 구현한 결과물은 아니다. 현재 정보 기반 API는 `/api/v2`이며 상세 계약은 [BACKEND-V2.md](BACKEND-V2.md)에 있다.

스티비 이메일 어댑터와 Liner 연동부를 포함한다. Bivia와 채널톡은 제외했다. API 키는 공란, 외부 연동은 기본 비활성이다. 포함된 시드는 가상 데모로 실제 지원 조건이 아니며 운영에서 거부된다. 실제 발송·공개 서비스 배포·클라우드 생성은 이 업로드에 포함하지 않는다.

업로드에서 제외하고 로컬에 보존한 항목:

- `.env.local` 등 실제 환경 파일, `data/`, `artifacts/`, `node_modules/`, `.next/`, 로그·캐시.
- 개인 기획·상세 설계·Word 문서와 문서 생성용 Python 스크립트.
- `docs/sources/`의 Miro 원문 읽기 기록. Miro 접근 기록의 요약 문서는 개발 맥락을 위해 보존했다.

기존 기획 문서를 참조하는 예전 API 문서의 일부 상대 경로는 로컬 참고 자료를 가리킨다. 현재 구현·설정은 README와 BACKEND-V2.md가 우선한다.

실행은 Node.js 24에서 `npm ci`, `npm run setup`, `npm run dev` 순서다. 로컬 PGlite는 한 프로세스에서만 사용하고, 앱을 끈 뒤 마이그레이션·CLI 작업을 실행한다. 다중 앱·작업 프로세스는 PostgreSQL의 `MAWD_DATABASE_URL`을 사용한다.

업로드 전 검증: 타입 검사·76개 테스트, 형식 검사, 배포 빌드, 기존 API와 v2 API의 로컬 HTTP 스모크가 모두 통과했다. 합성 데이터용 별도 DB를 사용했고 검증 서버는 종료했다. 실제 외부 API 성공이나 이메일 수신 검증을 뜻하지 않는다.
